## Part 3: Python Implementation of the Dream-RSI Engine

Here is the lightweight Python architecture implementing the **Replay Simulator** and **Dream Policy Evaluator** that your agent can run locally:

```python
# code/dream_rsi_engine.py
import json
import os
from dataclasses import dataclass
from typing import Callable, Dict, List, Any

@dataclass
class TrajectoryRecord:
    case_id: str
    user_id: str
    audit_at: str
    observed_resources: List[Dict[str, Any]]
    expected_status: str
    expected_steps: List[Dict[str, Any]]

class DreamWorldSimulator:
    """
    Evolving World Replay Simulator (Dream-RSI).
    Provides zero-token, instant off-policy simulation over recorded trajectories.
    """
    def __init__(self, cache_file: str = "cache/world_trajectories.json"):
        self.cache_file = cache_file
        self.trajectories: Dict[str, TrajectoryRecord] = {}
        self.load_world()

    def record_trajectory(self, record: TrajectoryRecord):
        self.trajectories[record.case_id] = record

    def save_world(self):
        os.makedirs(os.path.dirname(self.cache_file), exist_ok=True)
        data = {k: v.__dict__ for k, v in self.trajectories.items()}
        with open(self.cache_file, "w", encoding="utf-8") as f:
            json.dump(data, f, indent=2)

    def load_world(self):
        if os.path.exists(self.cache_file):
            with open(self.cache_file, "r", encoding="utf-8") as f:
                data = json.load(f)
            for k, v in data.items():
                self.trajectories[k] = TrajectoryRecord(**v)

    def dream_counterfactual(self, candidate_policy: Callable[[TrajectoryRecord], Any]) -> Dict[str, float]:
        """
        Runs an alternative exploration policy over the replay simulator.
        Returns accuracy, step recall, and edge-case resolution rates.
        """
        total = len(self.trajectories)
        if total == 0:
            return {"accuracy": 0.0, "total_cases": 0}

        correct_status = 0
        step_matches = 0

        for case_id, traj in self.trajectories.items():
            pred_status, pred_steps = candidate_policy(traj)
            if pred_status == traj.expected_status:
                correct_status += 1
            if len(pred_steps) == len(traj.expected_steps):
                step_matches += 1

        return {
            "status_accuracy": correct_status / total,
            "step_count_accuracy": step_matches / total,
            "total_simulated": total
        }
```

### Key Takeaway for Implementation

The core strength of the Dream-RSI framework lies in **closing the loop between discovery and reflection**:
1. It avoids burning runtime LLM tokens by caching environmental state into an immutable **Evolving World Simulator**.
2. It tests algorithmic mutations (such as generalized account lookups and multilingual regexes) across past historical failures in the **Dream Phase**.
3. It only deploys code changes when the dreamed counterfactual proves superior and achieves a **100% pass rate** on the regression test harness.
